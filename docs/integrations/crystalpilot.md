# CrystalPilot integration — gate golden cases and evidence verification

**Status:** implemented and tested offline. CrystalPilot is the evidence-gated
NVIDIA Nemotron experiment agent in
[Takzin1/crystaltwinai](https://github.com/Takzin1/crystaltwinai) (`/pilot`).

## What actually runs where

| Component | Runs in | Source of truth |
|---|---|---|
| Research gate used at runtime by the hosted app | CrystalTwinAI (TypeScript port, `src/lib/pilot/gate.ts`) | this repository's `qfabric.orchestration` |
| Gate golden cases | QFabric `scripts/export_gate_golden.py` → `tests/fixtures/research_gate_golden.json` | real Python gate output |
| Independent evidence verifier | QFabric `qfabric.evidence`, `scripts/crystalpilot_verify.py` | re-runs the real Python gate |

The hosted Next.js app cannot execute this Python package, so it runs a port.
The port is held to the Python behaviour by 39 golden cases (accept, reject
and refusal paths, including NaN, duplicate keys, prompt-injection fields and
hardware actions). `tests/test_gate_golden.py` fails if the gate changes
without regenerating the golden file; the CrystalTwinAI test suite fails if
the port diverges from it.

## Evidence verification

```bash
python scripts/crystalpilot_verify.py crystalpilot-run-XXXX.json
```

Checks: strict JSON (duplicate keys / NaN refused), canonical-JSON body digest
(RFC 8785 style, ECMAScript number formatting — identical to the TypeScript
implementation), snapshot SHA-256 + `parse_snapshot`, model-content SHA-256,
`make_assessment` and `make_review` recomputed from the embedded bytes, and
workflow state-transition validity.

It does **not** re-run the CrystalTwinAI simulation (TypeScript engine); use
CrystalPilot's `npm run verify:evidence` for replay. A PASS is file integrity
plus gate/review consistency. It is not producer authentication, not proof of
a live model call and not scientific validation. Live inference records are
reported as `warn` (self-reported) by this verifier.

## Contracts

`crystaltwin-qfabric-snapshot/1`, `qfabric-research-proposal/1`,
`qfabric-research-assessment/1` and `qfabric-human-review/1` are unchanged.
New: `qfabric-gate-golden/1` (test fixture) and the consumed
`crystalpilot-evidence/1` (defined by CrystalPilot).

The fixtures `tests/fixtures/crystalpilot_evidence.*.offline.json` were
generated by CrystalTwinAI `scripts/export-evidence-fixtures.mts` in OFFLINE
fixture mode; no model was called to create them.
